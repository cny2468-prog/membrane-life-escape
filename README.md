# 막 너머의 생명

고등학교 2학년 「세포와 물질대사」의 광합성과 세포호흡을 다루는 학생용 방탈출 게임.

5개 방에서 4개 퍼즐과 최종 콘솔을 순서대로 통과한다. 사건 재현 시뮬레이션, 하트·노트 회복, 단계별 시간·오답·완료 시 하트 및 탈출 결과, DOCX 활동지, 완료 후 단계 복습을 포함한다. 밤 관측은 미세한 빛도 제공되지 않는 완전한 암조건으로 명시했다.

시작할 때 학번과 이름을 입력한 뒤 캐릭터를 선택한다. 게임 중 캐릭터 머리 위에 이름이 표시되고 탈출 결과에는 선택한 캐릭터·이름·학번이 함께 나타난다. 학생 정보도 이 기기의 브라우저에만 저장하며 서버로 전송하지 않는다. 이전 기록에 학생 정보가 없으면 이어하기 때 입력만 추가하고 기존 진행·풀이·하트는 유지한다.

GitHub Pages에서 main 브랜치의 /docs를 공개한다. 별도 로그인·설치·API 키·서버 데이터베이스가 필요 없다. 게임 진행과 풀이 기록은 각 기기의 브라우저에 자동 저장되며, 다른 기기·브라우저·주소와 자동 동기화되지 않는다. 활동지와 학습 기록은 DOCX로 내려받을 수 있다.

이 저장소는 교사가 승인한 cell-metabolism-escape-classroom의 별도 정적 배포본이다. 기존 my-escape와 원본 dossamlab/escape-kit는 변경하지 않았다.
